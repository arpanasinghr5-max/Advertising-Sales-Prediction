# Advertising-Sales-Prediction
Advertising Sales Prediction using Multiple Linear Regression with Python, featuring data preprocessing, EDA, visualization, and predictive analytics.

## Project Overview

Companies invest heavily in advertising across multiple platforms such as TV, Radio, and Newspaper. This project aims to determine how these advertising channels influence product sales and develops a predictive model for estimating future sales.

The project demonstrates the complete machine learning workflow from data exploration to model evaluation.

## Objectives

- Perform data cleaning and preprocessing
- Explore relationships between advertising channels and sales
- Visualize important trends and correlations
- Build a Multiple Linear Regression model
- Evaluate model performance using regression metrics
- Predict sales based on advertising expenditure

## Dataset

The dataset contains advertising budgets spent on different media platforms along with the corresponding product sales.
